# Původní startovní dokumentace

Tento soubor původně sloužil jako zadání pro založení projektu ve VS Code a
PlatformIO. Milníky M0 až M5 už byly implementované a původní dvacetistránkový
návrh začal míchat historické požadavky s aktuálním stavem.

Aktuální dokumentace je rozdělena podle účelu:

- [README](../README.md): spuštění, funkce, API a rozcestník,
- [aktuální stav](PROJECT_STATUS.md): stručně hotovo / částečně / plán,
- [specifikace](PV_DASHBOARD_SPEC.md): současné požadavky a funkční rozsah,
- [architektura](ARCHITECTURE.md): moduly, datové toky a omezení hlavní smyčky,
- [displej](DISPLAY.md): ověřený hardware a refresh strategie,
- [integrace](FVE_INTEGRATION_HANDOFF.md): GoodWe a AZRouter,
- [počasí](WEATHER_PROVIDERS.md): provideři, lokality a lifecycle WeatherWorkeru,
- [výkon](PERFORMANCE.md): metodika a historická měření,
- [roadmapa](ROADMAP.md): další implementační kroky,
- [projektový backlog](PROJECT_INTENT_BACKLOG.md): zachycené budoucí záměry.

Historie projektu zůstává dostupná v Git historii. Tento soubor je ponechaný
kvůli starším odkazům.
