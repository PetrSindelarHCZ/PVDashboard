# KPI font candidates

These font files are temporary design candidates used only to rasterize 1-bit
diagnostic previews for the 800x480 e-paper display.

- Chakra Petch Bold — Google Fonts, SIL Open Font License 1.1
- Quantico Bold — Google Fonts, SIL Open Font License 1.1
- Aldrich Regular — Google Fonts, SIL Open Font License 1.1

Upstream source: https://github.com/google/fonts

The TTF files live under tools/ and are not linked into the ESP32 firmware.
Only the generated 1-bit glyph data is compiled for the diagnostic page.
